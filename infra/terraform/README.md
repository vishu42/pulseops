# PulseOps Terraform Infrastructure

This directory replaces the AWS CLI runbooks with Terraform/OpenTofu modules for the AWS and Kubernetes infrastructure described in `docs/aws.md`.

## Layout

- `modules/network`: VPC, subnets, NAT, route tables, and VPC endpoints.
- `modules/security`: ALB and RDS security groups.
- `modules/eks`: EKS control plane, managed node groups, OIDC provider, IAM roles, and EKS add-ons.
- `modules/ecr`: service image repositories.
- `modules/data`: S3 archive bucket, RDS PostgreSQL, and Secrets Manager credentials.
- `modules/kubernetes-addons`: AWS Load Balancer Controller, metrics-server, Strimzi, Kafka storage class, Kafka cluster, and topics.

## Usage

```sh
cd infra/terraform
cp terraform.tfvars.example terraform.tfvars
terraform init
terraform plan
terraform apply
```

OpenTofu works with the same files:

```sh
tofu init
tofu plan
tofu apply
```

After apply:

```sh
aws eks update-kubeconfig --region "$(terraform output -raw aws_region 2>/dev/null || echo us-east-1)" --name "$(terraform output -raw cluster_name)"
```

The RDS password is generated by Terraform and stored in AWS Secrets Manager. The secret ARN is exposed as a sensitive output.

## Notes

- These modules create paid AWS resources.
- The network module keeps the script's cost-saving single NAT Gateway design.
- The EKS module lets EKS create and manage the cluster security group.
- The RDS instance defaults to Multi-AZ with deletion protection.
- The Kubernetes add-ons module expects the EKS cluster to be reachable from the machine running Terraform.
